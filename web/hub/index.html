      Use Backyard in Claude

      Add Backyard to Claude as a connector: Claude can then publish and update sites for you. You sign in with your usual account and approve the connection once.

      Connector URL
      1. Claude on the web, desktop or phone

        Customize → Connectors → Add custom connector. Name it Backyard, paste the URL, then Connect and sign in.

      2. For a whole Team or Enterprise

        Organization owners add it once under Organization settings → Connectors → Add → Custom → Web; then everyone just clicks Connect.

      3. Claude Code 
        claude mcp add --transport http backyard

        Then run /mcp in Claude Code and choose Authenticate.

      Your connections

        No connections yet. Each app you connect shows up here, and you can disconnect it at any time.

        Disconnect a person

        Admins: end all Claude connections of one person, for example when they leave. They can connect again for as long as they can still sign in.

        Use the CLI

        Deploy from your terminal or CI with diffed uploads.

        1. Install 
          curl -fsSL https://raw.githubusercontent.com/thasami/backyard/main/scripts/install.sh | sh

          Or with Go: go install github.com/thasami/backyard/cmd/backyard@latest

        2. Sign in 
          backyard login

        3. Create & deploy a site 
          backyard init my-site && cd my-site && backyard deploy

        Prebuilt binaries: GitHub releases.

        For agents

        Coding agents can build and ship sites end to end. Point them at the docs, or install the Claude skill and MCP server.

        /llms.txt /llms-full.txt SDK typings API docs
        Install the Claude skill 
        backyard skill install --global

        claude mcp add backyard -- backyard mcp
