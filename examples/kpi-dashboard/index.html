Connect your warehouse

Add a named query to the Backyard server config (backyard.yaml). It should return one row per day: a date column followed by numeric columns. Then reload this page.

warehouse:
  sources:
    default:
      type: postgres            # or bigquery / athena
      dsn: ${ANALYTICS_DSN}
  queries:
    kpi_daily:
      description: Orders and returns per day
      params: [days]
      sql: |
        SELECT day, orders, returns
        FROM analytics.daily_orders
        WHERE day >= CURRENT_DATE - CAST(@days AS integer)
        ORDER BY day

Use another named query with ?query=<name>.
